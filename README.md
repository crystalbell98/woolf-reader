# 纸间研读 · 伍尔夫三书

在线阅读：https://crystalbell98.github.io/woolf-reader/

三本弗吉尼亚·伍尔夫的英文原著，配中文、插画、逐词查词和助记词卡：

| 书 | 内容 | 中文 |
|---|---|---|
| 一间自己的房间（A Room of One’s Own，1929） | 6 章精读卡，全书英式英语朗读 | 本站自写意译 |
| 奥兰多（Orlando，1928） | 6 章全文，第 1–2 章有朗读 | 本站据英文原文自译 |
| 达洛维夫人（Mrs Dalloway，1925） | 7 个阅读单元，全文 | 本站自写意译 |

## 怎么用

- 点正文里的英文单词，看这句话里的词义和助记图。
- 点「书架」切换三本书。
- 生词记录只存在你自己的浏览器里，换设备或清除浏览器数据后不会保留。

## 下载

- 全部助记卡：打开 [Releases](https://github.com/crystalbell98/woolf-reader/releases/latest)，下载 `woolf-word-cards.zip`。图片与网页里的词图相同。
- 离线阅读：点本页右上角 Code → Download ZIP，解压后用浏览器打开 `index.html`。

## 来源与许可

- 三本书的英文原文均已进入公有领域。
- 中文由本站撰写，不使用任何已出版的中文译本。
- 查词释义部分来自 ECDICT，许可见 `LICENSE-ECDICT.txt`。
- 插画、助记卡和朗读均为生成内容。
